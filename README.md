# Gym Management System

Sistema integral de gestión para gimnasios diseñado para centralizar y optimizar la administración operativa diaria, el control de accesos y el seguimiento de socios.

### 📌 Sobre el proyecto

La plataforma busca resolver las necesidades comunes en la administración deportiva: altas y seguimiento de miembros, gestión de membresías y pagos, control de asistencias y asignación de rutinas o clases. Diseñada bajo una arquitectura cliente-servidor desacoplada, prioriza la rapidez de carga, la escalabilidad de datos y una experiencia de usuario intuitiva.

### 🚀 Stack Tecnológico

- **Frontend:** React (SPA reactiva, modular y enfocada en una experiencia de usuario fluida).
- **Backend:** Node.js con Express (API RESTful para el manejo de lógica de negocio, endpoints seguros y orquestación de datos).
- **Base de Datos & Servicios:** Supabase (PostgreSQL relacional, autenticación y persistencia escalable en la nube).

### ✨ Características principales (en desarrollo)

- **Gestión de Socios:** Registro completo, estados de membresía y perfiles individuales.
- **Control de Membresías y Pagos:** Seguimiento de vencimientos, cobros y tipos de planes.
- **Asistencia y Acceso:** Registro de entradas y concurrencia diaria.
- **Roles y Seguridad:** Panel administrativo protegido con políticas de acceso basadas en usuario.
