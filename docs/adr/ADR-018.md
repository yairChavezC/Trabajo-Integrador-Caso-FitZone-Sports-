# ADR-018 — Diálogo de confirmación y notificaciones al usuario

- **Estado:** Aceptado
- **Fecha:** 2026-11-16
- **Autor:** Acosta, Marcela
- **Sprint:** 4
- **Requisitos relacionados:** RF-07, RF-08

## Contexto

El usuario necesita confirmar acciones destructivas (cancelar reserva, eliminar clase) y recibir notificaciones sobre ofertas de lista de espera.

## Alternativas consideradas

| Alternativa | A favor | En contra | Por qué se descartó |
|---|---|---|---|
| `window.confirm` nativo | Simple | Feo, no customizable, bloqueante | Descartada |
| Modal custom sin librería | Control total | Reimplementar accesibilidad | Descartada |
| `ConfirmDialog` con clases CSS | Reutilizable, accesible, sin dependencias | Requiere CSS dedicado | **Adoptada** |
| Librería externa (react-modal) | Madura | Dependencia extra | Descartada |

## Decisión

- `ConfirmDialog`: diálogo modal con `role="dialog"`, `aria-modal`, estilos en CSS (sin inline styles).
- Notificaciones en `notificaciones_clase_grupal`: el socio ve ofertas pendientes en la agenda.
- `EstadoBadge`: componente que muestra el estado de inscripción con color.

## Consecuencias

- **Positivas:** UX consistente, accesible, sin dependencias externas.
- **Negativas:** Componente custom que mantener.
- **Deuda asumida:** Agregar animaciones y focus trap.
